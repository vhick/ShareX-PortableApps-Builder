## Provenance and scope

The upstream source is not built from scratch in this PORTABLEAPPS implementation. The official portable binary is verified against release-body SHA-256 before extraction. Exact-tag source ZIP is downloaded by immutable 40-character commit and bundled. No DLLs, executable placeholders, PAF installers, packages or `Data` user profiles are committed to the builder repository.

The source release manifest may update in future. This builder fails rather than accepts a release missing an official SHA-256, unsupported platform or expected asset. If a new upstream release materially changes portable path semantics, **a successful download does not confirm the old launcher still works**; rerun manual acceptance.
